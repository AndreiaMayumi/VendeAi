# VendeAí

Sistema de gerenciamento de vendas desenvolvido como projeto acadêmico da disciplina de Engenharia de Software.

## 📌 Sobre o projeto

O **VendeAí** tem como objetivo auxiliar no gerenciamento de vendas, reunindo funcionalidades para controle de produtos, clientes, pedidos, estoque e vendedores.

O projeto contempla as etapas de requisitos, modelagem, arquitetura, implementação e testes.
